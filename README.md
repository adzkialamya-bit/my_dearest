# The Chapters of My Heart — For Hamzah

A self-contained, static website made with HTML, CSS, and vanilla JavaScript.

## Included
- Five interactive chapters, written in English
- Modal chapter navigation with previous/next controls
- Original uploaded photographs in the scrapbook gallery
- First Tinder conversation screenshot in Chapter 03
- Interactive envelope with rotating personal notes
- A gentle, original ambient instrumental generated locally with Web Audio API (no external audio file or copyrighted song)
- Responsive layout for mobile and desktop

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Press **Play music** to start the original ambient instrumental. Browsers require a user gesture before audio can play.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

All photographs are stored locally in `assets/`. No build step is required.
